🚀 Degeris Panel

Degeris Team یک پنل مدیریتی جدید و قدرتمند برای مدیریت سرویس‌ها و تنظیمات سرور ارائه می‌کند.

ما در Degeris تلاش کردیم یک تجربه‌ی ساده، سریع و کاربردی ایجاد کنیم تا نصب و راه‌اندازی پنل تا حد ممکن راحت باشد.

⚡ نصب سریع

برای نصب، کافی است دستور زیر را روی سرور خود اجرا کنید:
'''bash
bash <(curl -fsSL https://raw.githubusercontent.com/Degeris/Degeris/main/install.sh)

کافی است دستور بالا را کپی کنید و داخل ترمینال سرور Paste کنید.

اسکریپت به‌صورت خودکار:

1. فایل‌های موردنیاز را دریافت می‌کند.
2. بسته‌ی نصب را دانلود می‌کند.
3. فایل‌ها را استخراج می‌کند.
4. فرآیند نصب را اجرا می‌کند.
5. مراحل لازم برای راه‌اندازی پنل را انجام می‌دهد.

📦 بدون نیاز به دانلود دستی

نیازی نیست فایل‌های بزرگ را به‌صورت دستی روی سرور دانلود یا استخراج کنید. فرآیند نصب توسط Installer انجام می‌شود.

📥 Installation

Step 1

به سرور خود متصل شوید.

Step 2

دستور زیر را اجرا کنید:

bash <(curl -fsSL https://raw.githubusercontent.com/Degeris/Degeris/main/install.sh)

Step 3

منتظر بمانید تا فرآیند نصب کامل شود.
