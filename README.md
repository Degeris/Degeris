# 🚀 Degeris Panel — نسخه 1.5.2

با سلام و درود 🌹

این پنل نسخه **فورک‌شده و توسعه‌یافته** از پنل XUI است که توسط **Degeris Team** آماده و منتشر شده است.

نسخه فعلی پنل **1.5.2** است و با هدف ارائه یک تجربه ساده، سریع و کاربردی برای مدیریت سرویس‌های VPN و سرور توسعه داده شده است.

## ⚡ آموزش نصب

برای نصب پنل، ابتدا وارد سرور خود شوید.

سپس دستور زیر را کپی کرده و داخل ترمینال سرور وارد کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Degeris/Degeris/main/install.sh)
```

پس از اجرای دستور، فرآیند نصب به‌صورت خودکار آغاز می‌شود.

Installer فایل‌های موردنیاز را دریافت و آماده‌سازی می‌کند و نرم‌افزارها و پیش‌نیازهای لازم نیز به‌صورت خودکار نصب می‌شوند؛ بنابراین نیازی نیست کار خاصی به‌صورت دستی انجام دهید.

## ▶️ اجرای پنل

پس از اینکه نصب با موفقیت به پایان رسید، برای باز کردن منوی مدیریت پنل کافی است دستور زیر را در ترمینال وارد کنید:

```bash
Degerist
```

یا:

```bash
degerist
```

پنل به‌صورت پیش‌فرض روی پورت زیر اجرا می‌شود:

```text
2053
```

## 📦 پیش‌نیازها

تمام نرم‌افزارها و پیش‌نیازهای موردنیاز برای اجرای پنل توسط Installer بررسی و نصب می‌شوند.

در نتیجه برای نصب اولیه نیازی به نصب دستی موارد موردنیاز ندارید.
