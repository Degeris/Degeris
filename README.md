⚡ نصب سریع

برای نصب پنل، کافی است دستور زیر را روی سرور خود اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Degeris/Degeris/main/install.sh)
```

کافی است دستور بالا را کپی کنید و داخل ترمینال سرور Paste کنید؛ نصب به‌صورت خودکار انجام می‌شود.
